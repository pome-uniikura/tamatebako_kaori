# WEB テスト対策（玉手箱・TG-WEB）

玉手箱と TG-WEB（従来型・新型）の対策をするための、個人用の学習サイトです。[資格ロードマップ（salesforce-learning-hub）](https://github.com/pome-uniikura/salesforce-learning-hub) と同じ仕組みで作っています。

公開先: https://pome-uniikura.github.io/tamatebako_kaori/ （検索エンジンには載らない設定）

## できること

| 機能 | 内容 |
|---|---|
| ホーム | いま取り組む科目（最後に学習した科目）と次にやること、今日の学習量・連続学習日数・復習待ち、テストと科目の一覧と進み具合 |
| 科目ページ | 進み具合と次にやること、苦手な形式、受検予定日とペース、出題形式ごとの進捗・正答率・本番形式の最高点、テストの概要（問題数・時間・1 問あたりの秒数・電卓など） |
| レッスン | 形式ごとの解き方。例題・ひっかけ注意・コツ・図（展開図や一筆書きの図、ベン図など）。PC は横に目次、スマホは目次ボタン |
| 聞く（読み上げ） | 「はじめに」「言語」「性格検査」のレッスンを端末の日本語の音声で読み上げる |
| 練習問題 | 形式ごとに 20 問ずつ（まだ解いていない問題 → 前回間違えた問題を優先）。1 問ごとの回答時間と本番の目安を表示。読解は本文ごとにまとめて出題 |
| 本番形式 | 本番と同じ問題数・制限時間で解く（玉手箱は形式ごと、TG-WEB は科目ごと）。残り時間と「目安のペースより何問進んでいるか」を表示 |
| 図表 | 表・棒グラフ・折れ線グラフ・円グラフ・図形（SVG）を問題の中に表示 |
| 復習 | 間違えた問題が自動で集まり、2 回続けて正解すると外れる |
| 用語集 | テストをまたいで検索 |
| 記録と設定 | テーマと文字の大きさ、学習記録の書き出し・読み込み・削除、オフライン用の保存 |

スマホではメニューが画面の下に固定されます。Safari の共有ボタン →「ホーム画面に追加」で、アプリのように全画面で使えます（名前は「WEBテスト」）。

学習記録はブラウザの localStorage にだけ保存され、外部には送信しません。Salesforce の学習サイトと同じドメインですが、保存場所の名前を分けているので記録は混ざりません。

## 教材の状況

| テスト | 科目 | 形式（問題数） |
|---|---|---|
| はじめに | WEB テストの基本 | 見分け方・準備（レッスンのみ）、計算の基礎 80 問 |
| 玉手箱 | 計数 | 四則逆算 300 問、図表の読み取り 181 問、表の空欄推測 120 問 |
| 玉手箱 | 言語 | 論理的読解 64 問（16 文章）、趣旨判定 48 問（12 文章）、趣旨把握 12 問 |
| 玉手箱 | 英語 | 論理的読解 30 問（10 文章）、長文読解 30 問（10 文章） |
| TG-WEB 従来型 | 計数 | 図形 70 問、推論 60 問、暗号 40 問、集合・場合の数・数列 60 問 |
| TG-WEB 従来型 | 言語 | 空欄補充 29 問、並べ替え 20 問、長文読解 17 問 |
| TG-WEB | 英語 | 長文 25 問（5 文章） |
| TG-WEB 新型 | 計数 | 四則逆算 150 問、図表の読み取り 120 問 |
| TG-WEB 新型 | 言語 | 同義語 126 問、対義語 120 問、ことわざ・慣用句 110 問、読解 16 問 |
| 性格検査 | — | 玉手箱・TG-WEB・回答のコツ（レッスンのみ） |

合計 1,828 問、レッスン 28 本、用語集 53 語。

- 問題数・制限時間・見分け方は、就活情報サイトなどで広く紹介されている一般的な値です（2026 年 11 月 1 日に確認）。テストの提供元が仕様を公表しているわけではなく、企業によって異なることがあります。
- 合格ラインは公表されていないため、このサイトでは正答率の目安（TG-WEB 従来型の計数は 60%、ほかは 65〜70%）を使っています。

## 開発

```sh
npm install
npm run dev       # http://localhost:4321/tamatebako_kaori/
npm run generate  # 問題の JSON を作り直す（自動生成の問題と、テキストで書いた問題）
npm run validate  # 教材データの整合性チェック（--stats で形式ごとの問題数と正解の位置の偏り）
npm run build     # 型チェック + ビルド（dist/）
```

main に push すると GitHub Actions で GitHub Pages に公開されます（リポジトリの Settings → Pages → Source を「GitHub Actions」にしておく）。

## 構成

```
src/
  data/certs.json                  テスト（steps）・科目（certs）・出題形式（domains）と本番の問題数・時間
  data/text/<科目>/<名前>.txt       手書きの問題（読解・語彙など）。書き方は scripts/gen/textq.mjs の先頭
  data/questions/<科目>/<名前>.json  問題（npm run generate で作る。直接編集しない）
  data/glossary.json               用語集
  content/lessons/<科目>/<形式>.md   レッスン
  lib/quiz-runner.ts               練習・本番形式・復習の画面（本文・図表・タイマー・ペース）
  lib/figures.ts                   表・グラフ・SVG の表示
  lib/storage.ts                   学習記録の保存（ここだけが保存先を知っている）
  pages/data/[id].json.ts          科目ごとの問題データ（演習・復習のページが必要な分だけ読み込む）
scripts/generate-questions.mjs     問題を作る（乱数の種を固定しているので、何度実行しても同じ問題・同じ ID）
scripts/gen/                       形式ごとの問題の作り方
  shisoku.mjs  四則逆算            zuhyo.mjs   図表の読み取り      kuuran.mjs  表の空欄推測
  keisan.mjs   計算の基礎          tgweb.mjs   暗号・集合・順位推論・展開図・一筆書き・サイコロ
  usotsuki.mjs うそつき問題（全通りを調べて答えが 1 つか確かめる）
  goi.mjs / goi-data.mjs  同義語・対義語・ことわざ（意味の近い組は選択肢に混ぜない）
  textq.mjs    テキストで書いた問題を JSON にする
scripts/validate-content.mjs       教材データのチェック
```

### 問題を追加するには

- **読解・語彙などの手書きの問題**: `src/data/text/<科目>/` の `.txt` に追記して `npm run generate`
- **計算問題の数を増やす**: `scripts/generate-questions.mjs` の `count` を変えて `npm run generate`（既存の問題 ID は変わらない）
- **同義語・対義語・ことわざ**: `scripts/gen/goi-data.mjs` に組を追加して `npm run generate`

問題 ID の先頭（`tbk-`、`tgk-` など）は科目ごとに決まっていて、復習ページで科目を見分けるのに使います。

## 注意

問題・文章・英文はすべてオリジナルで、実際の試験問題ではありません。受検の際は、受検案内のメールや画面の表示を必ず確認してください。
