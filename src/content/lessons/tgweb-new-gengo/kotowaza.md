## はじめに：まとめて覚える

ことわざ・慣用句の問題は、**意味を選ぶ**問題と、**似た意味のことわざを選ぶ**問題が中心です。どちらも知識で決まるので、**意味の近いものをまとめて覚える**のが効率的です。

## 意味が近いことわざのグループ

| 意味 | ことわざ |
|---|---|
| 名人でも失敗することがある | 猿も木から落ちる、弘法にも筆の誤り、河童の川流れ |
| 価値のわからない人に与えても無駄 | 猫に小判、豚に真珠 |
| 用心深く準備する | 石橋を叩いて渡る、転ばぬ先の杖、備えあれば憂いなし |
| あせると失敗する | 急がば回れ、急いては事を仕損じる |
| 欲張ると両方失う | 二兎を追う者は一兎をも得ず、虻蜂取らず |
| 悪いことが重なる | 泣き面に蜂、弱り目に祟り目 |
| 手ごたえがない | 糠に釘、暖簾に腕押し |
| 小さなことも積み重なると大きくなる | 塵も積もれば山となる、雨垂れ石を穿つ |
| 取り返しがつかない | 覆水盆に返らず、後悔先に立たず |
| 思いがけない出来事 | 寝耳に水、青天の霹靂 |
| 都合のよいこと・幸運 | 渡りに船、棚からぼた餅 |
| 大差がない | 五十歩百歩、どんぐりの背比べ |

<div class="callout trap">
<p class="callout-title">ひっかけ注意：よく誤解される意味</p>

- **情けは人のためならず**：「親切にすると相手のためにならない」ではなく、「**親切にすれば、めぐりめぐって自分に返ってくる**」
- **気が置けない**：「油断できない」ではなく、「**遠慮しなくてよく、気楽につきあえる**」
- **役不足**（参考）：「力が足りない」ではなく、「**力量に対して役目が軽すぎる**」

</div>

## よく出る慣用句（体の部分を使うもの）

| 慣用句 | 意味 |
|---|---|
| 手を焼く | 扱いに困る |
| 舌を巻く | 非常に感心する |
| 肩を持つ | 味方をする |
| 腹を割る | 本心を打ち明ける |
| 顔が広い | 知り合いが多い |
| 足を洗う | よくない仕事や生活をやめる |
| 鼻にかける | 自慢する |
| 耳が痛い | 弱点を言われて聞くのがつらい |
| 腰が低い | 謙虚 |
| 歯に衣着せぬ | 遠慮せずにはっきり言う |

## まとめ

- 意味の近いことわざは**グループでまとめて**覚える
- 「情けは人のためならず」「気が置けない」など、**誤解されやすいもの**に注意
- 慣用句は**体の部分**を使うものが多い
